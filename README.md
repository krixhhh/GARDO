 # GARDIO – Digital Wardrobe & AI Outfit Recommendation

GARDIO is a digital wardrobe application that helps users organize their clothes and discover outfit combinations more easily.

The main idea behind this project is to make everyday outfit selection simpler by bringing wardrobe management and personalized styling together in one place.

## Features

- Digital wardrobe to organize clothing items.
- Outfit recommendations based on available clothes.
- AI-powered outfit suggestions.
- Weather-based outfit recommendations.
- User authentication and data management using Firebase.
- Modern web application interface.

## Tech Stack

- Next.js
- React.js
- JavaScript
- TypeScript
- CSS
- Firebase
- SQL

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder:

   cd YOUR_PROJECT_FOLDER

3. Install dependencies:

   npm install

4. Configure the required environment variables for Firebase and other services.

5. Start the development server:

   npm run dev

6. Open http://localhost:3000 in your browser.

## Project Objective

GARDIO aims to help users make better use of their existing wardrobe, explore new outfit combinations, and spend less time deciding what to wear.
